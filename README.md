# 監査論 すきまトレーナー

公認会計士試験・短答式の監査論を、机が使えないすきま時間で回すための一問一答アプリです。
片手で操作でき、途中で中断しても続きから再開できます。

## このリポジトリに教材は入っていません

アプリ本体（`index.html`）だけを置いています。
問題と解説は `cards.json` という別ファイルにあり、**端末の中だけ**に保存されます。

購入した教材の複製をインターネット上に置かないための作りです。
`.gitignore` で `cards.json` はコミットされないようにしてあります。

> **注意**
> GitHub Pages に置いたファイルは、リポジトリが Private でも
> URL を知っていれば誰でも取得できます（Enterprise Cloud を除く）。
> `cards.json` は絶対にこのリポジトリに入れないでください。

## 使い方

1. `cards.json` を端末に保存する
   （iPhone なら「ファイル」アプリ、Android なら「ダウンロード」）
2. 公開された URL を開く
3. 「教材ファイルを選ぶ」から `cards.json` を指定する
4. 共有メニューから「ホーム画面に追加」

2回目からは開くだけで前回の続きから始まります。
一度開いておけば、電波が入らない場所でも動きます。

## 収録

- 短答対策問題集 624肢
- 過年度本試験 400肢（令和6年Ⅰ回〜令和8年Ⅰ回）
- 78論点の解説（ひっかけの型 245件・関連論点 194件）

起動直後は問題集624肢だけが出ます。
学習が進むか本試験が近づくと、過去問を足すかどうかを聞いてきます。

## 記録の保存先

学習記録はブラウザの中（localStorage）に保存されます。
サーバには何も送りません。記録タブから書き出し・読み込みができるので、
機種変更のときはそこから移してください。

**ブラウザの履歴やサイトデータを消すと記録も消えます。** ときどき書き出しておくと安全です。

## ファイル構成

```
index.html              アプリ本体（教材は含まない）
manifest.webmanifest    ホーム画面に追加するための設定
sw.js                   オフラインで開くための取り置き
icon-192.png            アイコン
icon-512.png
apple-touch-icon.png
.nojekyll               GitHub の自動変換を止める
.gitignore              cards.json をコミットしないための設定
```

## 更新するとき

`index.html` を差し替えて Commit するだけです。次に開いたときに反映されます。
学習記録は消えません。

`cards.json` を新しくした場合は、記録タブの「教材を読み込み直す」から入れ替えてください。
こちらも学習記録は残ります。
